github 레포지토리 기준의 장부 구조를 만들어 보려 하고 있다.

github 레포지토리 자체를 git으로 표현해 업로드하는, 텍스트 파일 등 구조화된 데이터 자체가 올라가며,

이 레포를 내려받아 로컬 분석 툴 같은걸로 파일들을 로컬AI로 빠르게 분석하고 결과물을 도출하게 만드는

파일 자체는 실제 파일을 깃헙에 업로드하고, 레포 자체를 바로 내려받아 로컬 AI로 일정한 구조로 데이터를 분석하여

결과물을 도출하도록 하면, 텍스트로부터 경향성, 주제, 시간, 로그, 문체, 감정 등 다양한 의미있는 데이터를 도출해낼 수 있다.

네이티브 텍스트는 그대로 두고(원본 소스), Apache Parquet 이라는걸 사용하면 좋을 것 같아서,

Dev.Source.Book 에 업로드하여 링크 형태로 배지로 추가해 본다.

앞으로 의미있는 데이터나 도메인, 주제에 맞는 데이터를 수집하고 가공하는 능력은 매우 중요해질 것이고,

여기 안에서 인사이트를 얻거나 내가 필요한 정보를 얻는 능력이 정말 중요하지 않을까,

사람의 기억력이나 머리에는 한계가 있으니, 여러가지 정보들을 메모하고, 묶고, 저장하고, 업로드하고, 게시하여

데이터와 흔적, 기억, 시간의 기록을 남겨나가는 것은 앞으로도 중요하고, 이 일에 대해서는 멈추지 않을 것 같다.
